# AI Resume Screening & ATS Hiring – Exploratory Data Analysis

## Project Overview

This project focuses on performing Exploratory Data Analysis (EDA) on an AI Resume Screening and ATS Hiring dataset containing 100,000 candidate records and 44 variables.

The main objective is to analyze candidate information, resume quality, ATS scores, educational qualifications, work experience, technical assessment scores, and hiring outcomes to identify patterns and trends in the recruitment process.

Using Python and data visualization techniques, this project explores the relationship between candidate attributes and their final selection status (Selected or Rejected).

## Objectives

- Analyze candidate demographics, education, and professional experience.
- Understand the distribution of ATS scores.
- Compare selected and rejected candidates.
- Identify factors associated with candidate selection.
- Analyze job role and employment type distributions.
- Explore relationships between technical, interview, and assessment scores.
- Detect correlations and outliers in numerical features.
- Generate meaningful insights from recruitment data.

## Key Insights

- The dataset contains 100,000 candidate records and 44 variables.
- Selected candidates have higher average ATS scores than rejected candidates.
- Selected candidates show higher average work experience.
- Technical test scores are higher on average among selected candidates.
- Resume quality and keyword matching show differences between selected and rejected candidates.
- Candidate selection counts are relatively balanced across job roles and employment types.
- Education level alone does not show a major difference in selection rates in this dataset.

## Conclusion

This EDA project provides insights into candidate profiles, ATS performance, and recruitment outcomes. It highlights how different factors, including work experience, resume quality, ATS scores, and technical assessment performance, are associated with candidate selection.

The project demonstrates practical skills in Python-based data analysis, data cleaning, statistical exploration, data visualization, and extracting meaningful business insights.
